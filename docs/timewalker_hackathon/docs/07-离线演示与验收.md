# 双样板离线演示｜当前操作说明

更新：2026-10-15。状态见 [导航](README.md)，环境见 [09](09-本地开发交接.md)。本页替换早期单豫园包说明；旧实现证据可查 Git 与 [21](21-双样板落地与交接.md)。

## 支持范围

V3 的 Trail 已交付，但本轮没有扩展其离线缓存；首页断网时不请求 Trail 目录，避免干扰既有故事。

固定包包含豫园 `yuyuan-timewalker` 和天文馆 `shanghai-planetarium`，两包分支、图像、文字及记录可在提前准备后离线使用。天文馆使用讯号主题措辞。不是任意生成故事的自动离线管理；地图、在线模型、研究/生图和外部资料站点仍需网络。

构建收集实际资源并生成带版本与 SHA-256 的 manifest，预算 20 MiB；此前双包约 6.6 MiB，实际大小以当前构建及界面为准，不再沿用早期 2.1 MB 单包数字。生成图片不因进入候选就自动加入固定离线 allowlist。

## 现场准备

```bash
cd tour-hub-web
npm run build
npm run preview
```

1. 在正式构建的首页或故事侧栏点击「准备离线故事」（cosmos 为「准备离线讯号」）。开发热更新模式不准备离线缓存。
2. 等待界面明确准备完成；Worker 已注册不等于包已完整缓存。
3. 在演示设备分别进入两个样板、确认图片可读，再断网刷新，完成一次分支和记录下载。
4. 保留同一浏览器和站点 origin；隐身窗口、新设备或其他域名不共享缓存。更换端口也是新 origin。
5. 固定一份已验收的构建；现场不要临时替换 dist 或把新 Worker 与旧文件混用。

部署使用 HTTPS（本机回环开发例外）、正确 SPA 回退、正确 Worker 路径；Worker 文件更新策略不能永远缓存旧版。静态部署不自动提供在线 Agent API。

## 失败、更新与清理

- 素材逐项校验，失败会清理本次临时缓存，保留旧完整版本；不要把失败状态解释为已可离线。
- 新构建版本需要重新准备，旧完整标记不代表新内容已缓存；成功替换后清旧缓存。
- 浏览器可能逐出存储，状态检查会发现资源缺失；重新联网准备。
- 「清除离线素材」只清本功能缓存，不主动删除个人进度、草稿或其他应用缓存。
- 清理浏览器站点数据仍可能丢失个人成果；先导出/下载。没有提前准备时，首次离线访问不能保证成功。

## 验证证据与命令

```bash
# 安装浏览器工具后执行；不依赖正在运行的 dev server
npm run build
npm run test:offline
```

套件自行启动/关闭独立静态服务器，使用真实 Service Worker，验证损坏资源、失败回滚、版本替换、源站不响应时豫园五轮及天文馆两分支、刷新/新标签页、下载、逐出检测与作用域清理。最新通过记录见 [24](24-生成素材闭环与开发待办.md)，不是本次文档整理重新运行的结果。

新 Agent 成果需要离线演示时，可先发布并明确扩展固定资源清单，再 build 和完整验收；JSON 成果携带新增素材只解决迁移，不会安装 Service Worker 缓存。
