## 建议分工与集成点

| 工作线 | 所有权 | 第一个可合并结果 |
|---|---|---|
| 创作/编译 | 新中间契约、`server/agent` 编译模块；共享类型先与 UI 约定 | fixture 编译进原播放器，再接实际模型 |
| 声音/样板 | 两包 JSON、MP3、展示节奏、真机记录 | 一条完整样板带音频并可静音完成 |
| 工具/媒体 | Provider 与素材目录；沿用现有候选资源清单 | 真实服务到发布的单条闭环 |
| 演示/UI | Studio 展示与 08 讲稿 | 导入成功产物可在五分钟内讲完 |

从同一个功能分支最新 HEAD 开任务分支；共享契约、gateway、Studio 和样板 JSON 各指定负责人。每完成一个闭环小切片就 commit/push，集成前先同步成员更新，不强推。
