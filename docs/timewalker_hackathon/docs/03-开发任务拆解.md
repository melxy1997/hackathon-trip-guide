3. 备份 `.agent-jobs/rehearsals` 中真实返回的 `*.studio.json` 与请求证据，导入 `/publish`。采用成新 ID 草稿，检查地点/素材/分支后发布；不替换两个手工固定样板。失败保留真实错误与上游阶段，不重复无界重试。
