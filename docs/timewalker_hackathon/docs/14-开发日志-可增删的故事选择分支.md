# 开发日志：可增删的故事选择分支

日期：2026-10-12。工作分支：`feature/configurable-observation-hints`。

本轮继续选择答辩现场可直接演示、可自动验证的能力：创作者可以在已有选择章节中新增或删除故事方向，无需修改 V1 契约、引擎、后端或离线机制。

## 已实现

- `single_choice` 编辑区可新增选择，并可删除每个选择。
- 新选择生成不冲突的 ID、默认标题和恰好一个合法 `goTo`。
- 默认目标沿用第一个现有选项，但不会复制 `setVar` 或 `revealMemory` 副作用。
- 保持契约 2–10 个选项边界，越界操作给出直接提示。
- 新选择沿用现有标题、说明和下一章表单。
- React Flow 关系图自动增加或移除对应出口与边，正式播放器自动增加或移除选择按钮。
- 编辑仍复用原草稿保存、结构校验和预览链路。

## 验证证据

- Node 测试从 66 项增至 68 项，覆盖输入不可变、唯一 ID、默认动作、无副作用继承、删除还原和 2/10 边界。
- Builder Chromium 真实执行：采用模板、打开选择章、新增第三选择、重命名、配置目标、确认图多一条边、在正式播放器看到三个按钮、点击新选择到达配置章节、返回编辑器删除并恢复两项。
- 生产构建和 lint 通过，游客主包体积未变化。
