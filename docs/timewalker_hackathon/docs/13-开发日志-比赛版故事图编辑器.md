# 开发日志：比赛版故事图编辑器

> **文档状态：阶段记录，不是当前开发入口。** 本文中的“当前/待实现/下一步”、分支与测试数只对应文内记录阶段。最新能力见 [导航与当前状态](README.md)，领取任务见 [03](03-开发任务拆解.md)，环境接手见 [09](09-本地开发交接.md)。旧文涉及素材署名/许可复核不再作为本轮任务或验收门槛。

日期：2026-10-12。工作分支：`feature/configurable-observation-hints`。

本轮按比赛“简单、迅速、有完整演示链路”的目标，引入 MIT 开源库 `@xyflow/react@12.12.0`，在现有故事表单前增加可视化关系图，不扩展 V1 数据契约，也不建设通用低代码平台。

## 已实现

- 场景显示为可缩放、平移、自动适配视口的节点图；起点与终幕有独立标识。
- 点击节点同步选中原有章节表单。
- 支持新增、深复制和安全删除章节。
- 每个普通转移、选择项和观察完成动作都有独立出口；拖线到目标节点会替换该出口目标。
- 连线保留 `setVar`、`revealMemory` 等非跳转动作。
- 初始章、仍有入边的章节和唯一章节禁止删除；终幕不能添加出边。
- 图修改继续使用现有草稿保存、审核重置和共享结构校验。
- 原有章节列表和下一章选择框保留为手机端及操作回退。

React Flow 及编辑器按需加载：游客主包约 398 kB，只有进入发布后台故事编排时才下载约 197 kB 的编辑器 chunk。

## 自动化证据

- 新增纯函数测试覆盖出口提取、可达层级、新增、深复制、安全删除、普通/选择/观察连线和终幕保护。
- Node 测试由 59 项增至 66 项，全部通过。
- Builder Chromium 套件真实检查：5 节点画布、初始章删除保护、复制产生第 6 节点、不可达错误、删除恢复、审核重置、发布、双分支预览和 390px 布局。
- `npm run lint`：0 警告、0 错误。
- `npm run build`：成功并确认编辑器独立分包。

## 刻意不做

不保存画布坐标，不做撤销、多选、自定义节点模板、自动布局依赖或任意脚本。复杂条件仍由现有表单和契约控制；图编辑只负责已有安全出口的目标连接。
