# 开发日志：故事图错误精确定位

日期：2026-10-12。工作分支：`feature/configurable-observation-hints`。

本轮完成编辑器收口队列中的“图上错误定位”，让故事结构错误不再只是顶部文本，而能直接映射到章节和出口，为后续 Builder Agent 的 Critic 诊断提供稳定契约。

## 结构化诊断

- `ExperienceValidationError` 在保留既有错误文本和 `issues` 兼容性的同时，新增 `diagnostics`。
- 每条诊断可记录 `sceneId`，以及稳定路由身份：普通转场为 `transition:<index>`、选择出口为 `choice:<optionId>`、观察出口为 `observation`。
- Schema 校验内部保留每条出边的来源和 Handle，因此未知目标、循环、不可达章节等诊断无需解析中文错误字符串即可准确落点。

## 编辑体验

- 校验摘要下展示可点击的“定位”按钮，点击后选中章节、滚动并聚焦编辑区，同时说明具体问题。
- 关系图中的错误章节显示红色高对比边框和问题数量；错误出口的文字与 Handle 使用红色状态，错误连线同样进入警示样式。
- 问题数、节点可访问名称和定位按钮均提供文本语义，不只依赖颜色；修复后警示会立即消失。
- 循环会连带造成不可达章节，图中保留所有诊断，不把复杂错误误压缩为一个问题。

## 自动验收

新增 Schema 测试断言选择出口的未知目标能得到章节和 `choice:<optionId>` 级诊断，并保留原有中文错误文本。Builder Chromium 覆盖循环错误、问题节点、定位到编辑区、修复后清除警示、审核状态与发布闭环。

全量回归已通过：69 项 Node 测试、lint、类型检查、生产构建、主故事 Chromium、Builder Chromium、可玩性 Chromium 与五轮断网离线演练均通过，浏览器无异常或模型请求。
