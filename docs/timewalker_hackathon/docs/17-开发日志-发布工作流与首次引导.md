# 开发日志：发布工作流与首次故事编排引导

日期：2026-10-12。工作分支：`feature/configurable-observation-hints`。

本轮完成 Builder Agent 之前的编辑器收口：发布不再与编辑、生成和审核争抢同一个主动作，第一次打开故事编排器也有可跳过的操作说明。

## 发布工作流

- 发布页现在持续显示“确定范围、地点与内容、故事编排”三步；当前步骤有语义化 `aria-current="step"`，移动端保留完整步骤条而不是隐藏第一步。
- 每步只保留当前最重要的主动作：进入地点内容、生成地点内容或进入故事编排；只有故事已通过人工审核时，第三步的主按钮才是“发布体验”。
- 就绪提示会明确说明还缺少地点、故事或人工审核，并作为发布按钮的说明关联；上一步保留为次要操作。

## 不打断的首次引导

- 新增版本化本机偏好 `trip-guide:story-editor:onboarding:v1`，记录跳过或完成状态，不进入草稿、审核和发布数据。
- 第一次打开故事编辑器会显示三步紧凑卡片：选章节、编辑内容与出口、预览审核发布。它没有遮罩、不会夺取焦点，也不会阻止画布和表单操作。
- 所有引导控件具备明确文字及 44px 最小触控高度；存储不可用或数据损坏时安全回退为首次引导。

## 验收

新增 Node 测试覆盖引导首次显示、跳过、完成、版本化持久化与存储失败。Builder Chromium 覆盖引导步骤/跳过、工作流步骤语义、审核前发布禁用、结构修复、审核与发布。全量回归已通过：71 项 Node 测试、lint、生产构建、Builder Chromium、主故事 Chromium、可玩性 Chromium、五轮断网离线演练和 `git diff --check` 均无失败。
