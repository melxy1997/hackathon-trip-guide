# V3 五分钟答辩｜双故事、路线与运营

更新：2026-10-15。方向见 [25](25-时空漫游者-双模式产品方案与开发规划.md)，实际实现见 [26](26-Trail实现与开发交接.md) / [27](27-运营续接与体验收口.md)，能力/证据见 [导航](README.md)。以下是可执行 Web 操作稿，时间为彩排预算，仍需人工计时。

## 演示前准备

- 三入口：豫园故事、天文馆讯号、`/trail/yuyuan-four-sights`。故事提前准备离线；Trail 本轮需联网。
- `/publish` 顶部运营路线管理，可用「复制已发布版本」预备一份新 ID 路线草稿；真实开发态发布演示需 `npm run dev:full`，静态托管只展示导出，不能说已在线发布。
- Studio 导入一份已完成成果。真实 Provider 产物与固定手工样板、本地模板、自动化 fixture 分开说明；现场不赌长模型/生图请求。
- 准备 320/390px 画面、录屏和已下载卡片；真实手机上的声音、分享、下载另行试过再现场用。
- 演示进度和导演跳幕明确说明，不把点击/跳幕称为实地到站或消费核验。

## 五分钟主线

| 时间 | 操作 | 核心话术 |
|---|---|---|
| 0:00–0:30 | 首页两故事与主题路线 | 「故事让游客愿意开始，路线让游客知道怎样探索，工作台让这些体验可以被制作与分发。」 |
| 0:30–1:20 | 豫园一次选择、个人观察与手账片段 | 「不是回答标准答案；你的选择改变叙事，自己的发现进入旅程记录。家书是文学创作。」 |
| 1:20–1:55 | 天文馆开场、手动展区、航行记录 | 「从园林家书到深空讯号，同一契约和引擎，明显不同的主题表达；不使用室内定位。」 |
| 1:55–2:55 | Trail 手动四站、印章、可选推荐、纪念卡 | 「路线独立于故事，按顺序手动探索。推荐可跳过，实际点击留在本机事件记录中，不代表订单。」 |
| 2:55–3:35 | `/publish` 复制已发布版本或新建路线，改一处顺序/说明，发布后打开游客链接 | 「运营人员选已有地点、改说明，就能交付路线。开发服务真实写文件并回读，全新浏览器也能打开；本机草稿与发布有区别。」 |
| 3:35–4:30 | Studio 两概念、节拍、已保存插画、采用并编辑 | 「AI 帮故事制作，确定性工具负责路线配置。模型产物经校验成为可编辑草稿；不必为简单打卡引入智能体。」 |
| 4:30–5:00 | 统一底座与商业边界 | 「共享目的地内容，分别承载故事与路线。今天证明可用、可配置、可分发和可观察；真实交易收入留给后续合作验证。」 |

建议提前停在关键片段，不逐字朗读两篇故事。Trail 只有四次确认，可现场完整完成；若使用预置进度则明确说明。现场新建、复制或导入路线均生成独立 ID，不覆盖固定样板。修改后点「发布演示路线」，看到“已发布并重新读取校验”再复制链接。

## 八页幻灯片

1. 品牌与三入口：让世界成为你的故事。
2. 游客动机与运营难题：目的地需要体验组织层。
3. 豫园家书：选择、发现、情绪记忆。
4. 天文讯号：同一运行时跨题材复用。
5. 主题路线：手动集章、可选推荐、个人纪念卡。
6. 创作与运营：Story 的 AI 创作、Trail 的确定性配置与真实发布。
7. 架构与证据：共享地点/素材；独立 StoryEngine/TrailSession；实际验证与限制分开。
8. 商业路径：内容/路线制作服务、推荐机会、未来交易对接，不展示虚构佣金/ROI。

## 现场失败与问答

| 情况/问题 | 准确回答或退路 |
|---|---|
| 网络中断 | 已准备的两份故事继续；Trail 用已录制且注明来源的备份，不宣称已支持 Trail 离线 |
| 运营页无法写入 | 导出路线 JSON；没有实际数据/索引更新就不提供假分享链接 |
| 模型/生图无配置或慢 | 用成功保存的真实产物接续，或明确展示本地模板；配图失败保留原图 |
| 推荐代表真实商户吗？ | 首条为演示推荐；本机展示/点击证明可观测，不证明合作、交易或收益 |
| 有 GPS/图像识别/核销吗？ | 没有。手动确认与观察，位置和商业履约不作真实核验 |
| Agent 是自主执行吗？ | 当前为已接入的分阶段创作/研究/生图服务；Deep Agents 自主编排仍是后续增强 |
| 跨设备报表呢？ | 事件当前仅存本浏览器；另一浏览器可读已发布路线，但不共享事件和草稿 |
| 技术验证多少？ | 最新收口 Node 128 项、build/lint 和四套浏览器通过（27）；此前八套见 26，真实供应商和真机单列 |

商业主张是可制作和分发的体验产品，不是当场证明尚未发生的收入。素材署名/许可复核不作为本轮开发或答辩门槛。
