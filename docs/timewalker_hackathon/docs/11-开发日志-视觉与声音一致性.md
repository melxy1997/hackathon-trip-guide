# 开发日志：视觉与声音一致性

开始日期：2026-10-12。工作分支：`feature/configurable-observation-hints`，承接已推送的可配置观察提示实现。

本轮落实交接文档中的 P1“视觉与声音统一”，只改进通用播放器的阅读节奏、真实播放反馈和轻量过渡，不新增依赖、未授权媒体或故事专属运行时逻辑。确定性故事引擎、事件语义、默认静音和手动继续路径保持不变。

## 逻辑单元 0：范围与基线

### 已确认边界

- `storyEngine.ts` 已按声明顺序推进 narration/audio block，并使用场景 token 拒绝过期回调；本轮不改引擎。
- `useNarration.ts` 已具备静音、重播、音频/TTS、超时和失败回退，但没有向播放器暴露真实播放状态。
- 当前播放器只要存在待处理 block 就添加 `tw-speaking`，因此静音和失败时也会显示“正在朗读”的视觉状态。
- CSS 已支持 `prefers-reduced-motion`，后续过渡必须在该设置下关闭。
- 不新增图片、录音或音效；素材授权与真机音色仍由后续人工验收。

### 基线

承接上一轮最终验证：Node.js 24.21.0、npm 11.19.0；59 项测试、生产构建通过，lint 0 错误及 10 条既有警告。本机无 Chromium，浏览器脚本只能补充断言和语法检查，不能声称已实际运行。

## 逻辑单元 1：真实旁白播放反馈

### 实现

- `useNarration` 以场景 token 和 block ID 记录 `idle / playing / failed` 状态。
- 只有当前 block 已实际发起音频或系统语音播放时，播放器才添加朗读高亮。
- 静音、切换场景、重播、播放结束和失败都会撤销旧高亮；过期回调仍受既有 token 事件边界保护。
- 播放失败继续显示可读提示且不自动推进，游客始终可以阅读后手动继续。
- 浏览器脚本新增静音无高亮、失败清除高亮断言。

- `smoke-experience.mjs`、`smoke-playability.mjs` 通过语法检查；真实浏览器断言待 Chromium 环境补跑。

## 逻辑单元 2：阅读节奏与轻量过渡

### 实现

- 旁白段落按已读、当前待读、真实播放中和后续段落设置通用视觉层级；静音时当前段落保持清晰可读，不冒充正在播放。
- 播放中的段落使用轻量边线和背景呼吸反馈，不使用闪烁或大幅位移。
- 到站、读完进入互动、重播与场景切换时重新触发短暂淡入，帮助辨认状态变化，不引入等待步骤。
- 背景图只做克制淡入；图片失败时仍沿用纯文字路径。
- `prefers-reduced-motion: reduce` 下关闭内容、背景和播放提示的新增动画。
