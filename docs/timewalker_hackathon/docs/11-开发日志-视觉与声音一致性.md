# 开发日志：视觉与声音一致性

开始日期：2026-10-12。工作分支：`feature/configurable-observation-hints`，承接已推送的可配置观察提示实现。

本轮落实交接文档中的 P1“视觉与声音统一”，只改进通用播放器的阅读节奏、真实播放反馈和轻量过渡，不新增依赖、未授权媒体或故事专属运行时逻辑。确定性故事引擎、事件语义、默认静音和手动继续路径保持不变。

## 逻辑单元 0：范围与基线

### 已确认边界

- `storyEngine.ts` 已按声明顺序推进 narration/audio block，并使用场景 token 拒绝过期回调；本轮不改引擎。
- `useNarration.ts` 已具备静音、重播、音频/TTS、超时和失败回退，但没有向播放器暴露真实播放状态。
- 当前播放器只要存在待处理 block 就添加 `tw-speaking`，因此静音和失败时也会显示“正在朗读”的视觉状态。
- CSS 已支持 `prefers-reduced-motion`，后续过渡必须在该设置下关闭。
- 不新增图片、录音或音效；素材授权与真机音色仍由后续人工验收。

### 基线
