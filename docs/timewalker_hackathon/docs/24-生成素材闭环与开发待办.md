## 切片一：生图后端与持久素材

新增 `POST /api/agent/media`：`{ candidate, sceneId, artDirection?, confirmBilling:true }`。先校验当前候选和基础包，只替换指定章节的第一个图片块；其他章节、原候选及种子包不变。结果返回新候选、artifact、素材与耗时；仍需用户采用到独立草稿。

配置：服务端 `ARK_API_KEY`、`ARK_IMAGE_MODEL`，可选 `ARK_BASE_URL`（默认火山方舟 `/api/v3`）。每次最多生成一张 2K 图片，保持水印；一次并发，不自动重试计费调用；每候选最多六份新增资源。请求必须显式确认生图调用。无配置时明确报错，现有图片仍可用。当前环境没有这些凭据，本轮未发生真实生图调用。

图片立即下载到应用 `.agent-jobs/assets/`；可通过 `AGENT_ARTIFACT_DIR` 指定持久目录。按内容 SHA-256 命名，写文件再写元数据和请求缓存，临时文件 rename 提交。模型、提示词、尺寸、Provider 地址组成缓存键；相同请求重启后可复用，不再次调用计费服务。已生成文件不会因浏览器取消而主动清理。进程重启不代表正在运行的生图任务能恢复。

图片以 `/api/agent/assets/<hash>.<ext>` 访问；候选只存小型受控引用。API 根据本地元数据、长度、文件签名和哈希校验图片。生成服务的临时 URL 不写入候选或元数据，供应商 Authorization 不转发到 CDN。下载仅接受支持的 HTTPS 火山/字节图片域名，不跟随重定向；默认单图最多 5 MiB。新 URL 域名如超出适配器范围，需要后续明确扩展，不能静默跳过失败。

实现入口：`server/agent/imageProvider.ts`、`assetStore.ts`、`media.ts`、`gateway.ts`；新增自动化覆盖实际网关替图、候选校验、重启读取/缓存、损坏检测、媒体类型/大小、凭据隔离、缺配置与错误脱敏。验证使用测试图片与替身 Provider，不计为真实 Seedream 成功。
