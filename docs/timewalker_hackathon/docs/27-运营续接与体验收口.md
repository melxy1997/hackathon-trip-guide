## 切片一：路线运营续接（已完成）

入口为 `/publish` 的「运营路线管理」。新增能力：

- 根据标题、路线 ID 或基础景点 ID 查找路线。
- 「复制已发布版本」创建新 ID 草稿，不携带旧发布时间；未发布修改不会混入已发布副本。
- 「导入路线 JSON」读取编辑器实际导出的文件，严格校验格式、链接及基础包地点；生成新 ID，不覆盖原路线/已有草稿，不自动发布。
- 「移除本机草稿」需页内确认；只移除指定草稿，不删除已发布文件、游客进度、事件或其他草稿。放弃修改后仍可编辑已发布版本。
- 工作台和编辑器区分「本机未发布」「本机有未发布修改」「已发布 · 本机与线上一致」。比较规范化内容，忽略发布时间；发布状态读取失败标为未核实，不猜测。发布后刷新，内容一致时保留经读取确认的游客链接。

迁移操作：原浏览器进入路线编辑器→导出 JSON→新环境拉取同一基础景点数据→`/publish` 导入→预览→开发态发布→用另一个浏览器打开游客链接。JSON 上限 64 KB，只携带路线配置，**不是包含基础包/图片的便携压缩包**。基础景点缺失会提示先迁移；本机存储失败保留原文件，不跳转假装成功。

实现位置：`src/trail/TrailManager.tsx`、`trailDrafts.ts`、`src/pages/TrailEditorPage.tsx`。路线静态契约、游客会话键和 Story V1 不变；无需新增依赖或密钥。
