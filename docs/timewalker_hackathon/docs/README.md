## 目标与已经可用的能力

目标：Trip.com Hackathon，**快速可用、有演示效果**。游客产品为「时空漫游者 · 让世界成为你的故事」，技术表达为 Trip Experience Engine。现有核心是沉浸 Story 双样板与 Creative Studio；**V3 已实现独立 Trail 打卡与运营路线配置/开发态真实发布**。两种模式共享已有地点底座，故事保持产品差异化，打卡承担主题探索与未来运营连接。

素材作者、原图链接和许可复核不属于本轮开发任务或演示验收门槛。既有文学创作标签、结构校验、独立草稿与审核操作继续沿用，以免故事断链或覆盖成品。

| 能力 | 当前状态 | 接手时不要重复做 |
|---|---|---|
| 双样板 | 豫园家书、天文馆讯号都可完整运行 | 不再从头创建天文馆包或第二套播放器 |
| 通用引擎与主题 | 共用 V1；heritage/cosmos、letter/transmission、室内手动展区 | 不按景点 ID 写第二套界面 |
| 选择、观察与记录 | 分支反馈、人工标记/备注、刷新恢复、SVG/文字记录 | 不是视觉识别或真实 GPS |
| 创作编辑 | 图编辑、独立草稿、审核重置、预览和本地发布 | 不是生产 CMS/鉴权后台 |
| Studio 创作链 | 双概念→人工选择→节拍/V1 候选→采用并编辑 | 已实现接口与工作流，不再作为待建模块 |
| 研究 | Tavily Search/Extract，快照绑定简报与基础包，参与创作 | 适配已接入；真实账号成功尚待验证 |
| 配图 | Seedream 逐章插画、持久文件、缓存、候选替图 | 适配已接入；真实账号效果尚待验证 |
| 成果迁移 | 本机恢复、JSON 导入导出，导出携带新增图片/音频 | 不等于服务端 Job 恢复；素材目录不会随 Git 同步 |
| 固定样板离线 | 两包构建缓存、失败回滚、更新、清理 | 不覆盖任意新 Agent 草稿 |
| Deep Agents / 自主工具调用 | 未集成 | 当前研究与生图是确定性服务调用 |
| 云端 TTS / 持久 Job | 未实现 | 浏览器朗读与现有音频块可用 |

当前编译仍参考固定蓝图，由模型生成节拍与 V1；“更自由的中间剧本→确定性编译”尚待实现。两份固定样板是手工剧情，天文馆现有插画来自 image_gen，不是新 Agent/Seedream 自动生产证据。
